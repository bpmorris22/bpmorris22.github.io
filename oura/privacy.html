Privacy Policy

Last updated: 5 October 2026

This application is operated by Ben for personal use only. It uses the Oura API solely to read Ben's own personal health and sleep data (such as sleep, readiness, activity and heart rate) and display it on Ben's personal Home Assistant dashboards.

Data collected

Only data from Ben's own Oura account, accessed with his explicit authorisation through Oura's OAuth process. No data is collected from any other person.

How data is used and stored

Data is stored locally on Ben's private Home Assistant server and used only for his personal dashboards and automations.

Sharing

Data is not sold, shared with, or disclosed to any third parties.

Revoking access

Access can be revoked at any time from the Oura account settings or by removing the integration from Home Assistant.
